## The game

Become the breeze in a small autumn forest. Hold and drag to steer falling leaves into animal shelters. Each delivered leaf becomes part of a cozy blanket. Warm every friend before the frost arrives to move into the next chapter.

This is a gentle physics game about direction, timing, and care. Leaves tumble under gravity, branches interrupt their path, and water makes them unusable. There is an endless supply of leaves while the chapter timer is running: a missed leaf is a chance to try a different breeze.

## How to play

| Control | Action |
| :--- | :--- |
| **Hold and drag** with a mouse or finger | Aim the wind from the start of the drag toward its end |
| **Longer drag** | Stronger wind, up to a maximum |
| **Release** | Stop blowing and let the leaves settle |
| **Arrow keys / WASD** | Blow in a direction; combine keys for diagonals |
| **Space / Pause** | Pause or resume the chapter |
| **Restart** | Begin the current chapter again |
| **Fullscreen** | Enter or exit fullscreen; Escape also exits |
| **Sound** | Toggle soft, synthesized delivery chimes |

**Windkeeper's tip:** lift leaves to shelter height, guide them sideways, then release. The counter beneath each animal shows how many leaves it needs. A full blanket stays safely in place.

## Five chapters of kindness

| Chapter | Friends | A new challenge |
| :--- | :--- | :--- |
| **01 · The First Nest** | Robin | Learn to guide six leaves into a nest |
| **02 · Hedgehog Hollow** | Hazel & Pip | Share leaves between two hollows around a branch |

| **05 · Before the Frost** | Hazel, Maple & Clover | Warm three friends around branches and a stream |

## Made for Mini Jam 221

**Theme — Autumn:** falling leaves, copper and gold trees, woodland animals, and the arrival of frost shape the whole experience.

**Mandatory limitation — Staying Warm:** staying warm is the victory condition. Animals need insulating leaf blankets, and every shelter must be filled before the frost timer runs out. Leaves are functional insulation, rather than decorative collectibles.

**Content and provenance:** this project was created for this jam from a new implementation. All visual elements are drawn by Canvas code. Delivery chimes are generated by Web Audio oscillators. There are no external image, music, font, or asset-pack dependencies in the game, and no image or audio generation tools were used.

**AI disclosure:** AI assistance was used to write the source code, Canvas drawing instructions, documentation, and tests. The supplied jam rules prohibit the use of the wide majority of generative AI tools for images and sound. Code-drawn visuals and oscillator sounds are still AI-assisted in their implementation; disclose that honestly and seek organizer clarification if needed. This README does not claim organizer approval or guaranteed eligibility.

## Run locally

Requires **Node.js 20 or newer**. No package installation or build step is needed.

```sh
npm start
```

Open **http://127.0.0.1:4187** in a modern browser. Serve the game over HTTP: opening `index.html` directly can block JavaScript modules.

```sh
npm test
```

The tests cover warmth delivery in all five chapters, wet-leaf loss, wind direction, frost timeout, and branch collision. A small progress record may be stored locally in the browser; it contains no personal data. The game makes no network requests and has no analytics.

## Upload to itch.io

1. Create an **HTML** game project with the title **A Little Warmth**.
2. Upload `A-Little-Warmth-itch.zip`, provided with this project. Its root contains `index.html`, `style.css`, `game.js`, and `model.js`.
3. Select **This file will be played in the browser**.
4. Use an embed size of **1100 × 860**, enable the fullscreen button, and allow mobile play.
5. Describe the game and answer the jam's submission questions honestly, including the AI assistance described above.
6. Submit the itch.io game page to Mini Jam 221. A GitHub upload alone is not a jam submission.
